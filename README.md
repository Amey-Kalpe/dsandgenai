# AI Agents with LangGraph & LangChain

This repository demonstrates how to build AI agents and computational graphs using [LangGraph](https://github.com/langchain-ai/langgraph) and [LangChain](https://github.com/langchain-ai/langchain).

## Features

- **Graph-based AI workflows**: Compose complex agent behaviors as graphs.
- **LangChain integration**: Leverage LangChain's tools, chains, and memory.
- **Custom agents**: Build, test, and extend AI agents for various tasks.

## Getting Started

### Prerequisites

- Python 3.8+
- See `requirements.txt` for dependencies

### Installation

```bash
pip install -r requirements.txt
```

## Project Structure

- `agents/` — Custom agent implementations
- `graphs/` — Graph definitions and utilities
